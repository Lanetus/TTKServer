# Verified AWS Nitro enclave images, served by the root servers (ttk_root::FileImageTrustStore,
# GET /root-attestation) and fetched by clients and relays (ttk_ra_client::RootImageTrustStore).
#
# One PCR0 per line: the SHA-384 of the enclave image file (EIF), as 96 hex characters.
# `scripts/build-eif.sh` prints it ("PCR0" in out/<image>.json). Blank lines and text after `#`
# are ignored. Evidence from a non-debug Nitro enclave whose PCR0 is not listed is rejected; an
# empty list rejects every non-debug Nitro enclave.
#
# Every entry must be reproducible from a tagged commit (scripts/build-eif.sh) and labelled:
#   <PCR0> # ttk-<node> v<version> <arch> <commit>
# Never list a debug image (TTK_DEBUG=1, suffix _debug: it accepts mock next hops). Remove
# entries for images that are no longer deployed.
